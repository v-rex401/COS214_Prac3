Detailed Description

The abstract subject participant in the Observer pattern.

This class defines the interface for managing event notifications. It keeps a list of the interested observers but it does not strictly own the memory of the observers registered to it.

void EventSubject::attach ( EventObserver *  x)

Registers an observer to pass future event notifications to.

The subject stores a pointer to the observer but does not own it. The observer must remain alive when registered and detached before it is destroyed.

Parameters
